# AssistBall v2

## New in this version

- Drag the floating AssistBall anywhere on the desktop.
- A click without dragging opens the assistant.
- The chat window has a translucent glass/transparent appearance.
- Chat titlebar can be dragged.
- Screen capture behavior remains unchanged.

## Run

Terminal 1:
cd backend
python main.py

Terminal 2:
npm install
npm start
